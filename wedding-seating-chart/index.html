Wedding seating chart, in your browser

Paste the guest list, mark who must share a table and who must not, and set the table count. A constraint-aware search assigns seats. Drag anyone to fix it. Names are not uploaded.

  • Free up to 40 guests
  • Pro is $5 per event
  • Printable table cards with Pro
Guest names stay in this tab. They are not uploaded to New Prospects. Refreshing the page clears them. A license check goes to Gumroad with the key only, not with the guest list.

How to use it

  1. Paste guestsOne name per line. A repeated name is kept once.
  2. Add rulesMust sit together: one group per line, names separated by commas. Must not sit together: one pair per line, names separated by a vertical bar.
  3. Assign, then adjustSet how many tables and how many seats each has. Drag a name, or use Move on a phone. Assign again replaces those edits.

Frequently asked questions

Are guest names uploaded?

No. The list stays in this tab. Refreshing the page clears it. It is not sent to New Prospects.

What is free and what is Pro?

Free seats up to 40 guests and lets you drag people between tables. Pro is $5 per event, one time: unlimited guests, print or save as PDF, and CSV export.

What does one event mean?

One Gumroad purchase is for one event. This page has no server, so it cannot mark a key as used. When the event is over, choose Finish this event to clear Pro on this device. Entering a valid key again will unlock another event. That is an honor system. If you need more than one event, set the quantity at checkout.

What does must sit together mean?

The same table, not a specific chair. A group larger than the seats at one table cannot be placed. Two people cannot be both together and apart.

What if the rules cannot all be met?

The page seats as many people as it can and lists anyone left out, plus any rule a later drag breaks. You can move people anyway.

How do I print table cards?

Pro opens the browser print dialog. Choose Save as PDF there if you want a file. Each table is one block.
